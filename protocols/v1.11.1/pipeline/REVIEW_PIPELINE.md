# Review Pipeline

Version: `v1.11.1`

```text
verified intake and target identity
→ minimal/strict profile routing
→ complete review-surface collection and reconciliation
→ canonical review-package.json
→ active schema and semantic validation
→ single official project_decision
→ single official artifact builder
→ prompt semantic completeness validation
→ manifest from final bytes
→ official directory validation
→ live-Head-bound VerifiedReviewCompletion
→ official_owner_delivery
```

Candidate compatibility is allowed only before `review-package.json`, except for binding a verifier-created official minimal completion for strict same-Head reuse. Candidate output composition is not a pipeline stage. Any schema, projection, prompt-semantic, byte, manifest, provenance, or live-Head failure stops before owner output and leaves official stdout empty.
