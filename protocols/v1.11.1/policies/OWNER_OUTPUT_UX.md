# Owner Output UX

Version: `v1.11.1`

`OWNER_RESULT.fa.txt` remains exactly two visible Persian LF-terminated lines from the official registry. It contains no prompt body and no profile-selection commands.

When the projection requires a prompt, only `official_owner_delivery(VerifiedReviewCompletion)` may present the owner result and prompt together. Compact access fails before returning text.

`OWNER_PROFILE_COMMANDS.fa.txt` is always a separate verified artifact retrieved through `official_owner_profile_commands`. Missing, generic, Candidate-produced, or semantically incomplete prompt content is an internal blocked state and must not be converted into status wording or a later-delivery promise.
