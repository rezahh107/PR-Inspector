# Owner Decision Card Template

Use the exact visible structure below. Remove the `تصویر ذهنی` section when an analogy does not improve understanding.

```text
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
نتیجهٔ بررسی PR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

وضعیت: 🟢 سبز / 🟡 زرد / 🔴 قرمز / ⚪ گزارش نامعتبر

این تغییر چه کاری می‌کند؟
[حداکثر دو جمله ساده]

تصویر ذهنی:
[یک تشبیه کوتاه و دقیق؛ در صورت عدم نیاز، کل این بخش حذف شود]

چه چیزی ممکن است خراب شود؟
[پیامد واقعی برای کاربر، کسب‌وکار، داده یا سرویس]

چه چیزی بررسی شده؟
[خلاصهٔ ساده؛ بدون ابزار، کد یا لاگ]

چه چیزی هنوز مشخص نیست؟
[عدم‌قطعیت، یا «مورد مهمی باقی نمانده است»]

الان چه کار کنیم؟
[دقیقاً یک اقدام روشن]

آیا متخصص لازم است؟
بله / خیر
[دلیل کوتاه]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

Canonical final actions:

- `ادغام می‌تواند پس از تأیید لازم انجام شود.`
- `فعلاً ادغام نشود؛ ابتدا اقدام مشخص‌شده انجام شود.`
- `ادغام نشود؛ یک متخصص واجد صلاحیت باید بررسی کند.`
- `گزارش دیگر معتبر نیست و بررسی باید تکرار شود.`
